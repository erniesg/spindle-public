How pausing works

Pause lifts this site block in this browser profile only, then the browser restores it automatically at the shown time (Chrome alarms; it may run a little late, never early). Restarting the browser keeps the original end time, it does not start a new pause. Resource exceptions end when a pause starts. If site access was removed meanwhile, resuming reports the change as incomplete; Enable block again (which asks for site access) or Remove. Access is never regained silently. Private/Incognito windows are never blocked or paused by Spindle.

Review one resource

The host must have an explicitly configured Jev credential and cumulative budget. Sign-in or a site block alone never permits processing.

What review sends and its limits

Jev can assess this resource against your purpose through the signed-in native host, without recording. With your separate consent above, Spindle reads a bounded non-playing static page snapshot and sends its URL, purpose, title and up to 4096 bytes of text to Jev. Scripts/media are not played. Missing, ambiguous, stale or failed classification stays blocked; only strong agreement of the three semantic signals permits this exact URL and tab. Dynamic or unavailable text may remain uncertain. Supports query-free HTTP(S) paths and bounded YouTube watch?v= identity; unrelated parameters are rejected.

Blocked pages show the browser's blocked-request error. Return here through extension options to recover. Disabling/uninstalling bypasses blocking. SPA fencing is best-effort (250ms local URL observation, no continuous worker polling); already loaded media and subresources are not a strict pre-playback gate. Overrides are time-bounded and scoped to the exact case-sensitive URL, target tab, chosen purpose and policy version. Expiry, policy change and capture revocation re-gate access. Departure cancellation and SPA re-gating are asynchronous: a rapid HTTP redirect, JavaScript or SPA return to the same resource before cancellation can reach the server without renewed review. Resource-change invalidation is therefore limited, not atomic or single-use. Incidental worker suspension preserves unexpired overrides. Browser restarts retain the whole-site block, not exceptions. Jev exceptions also fail closed on worker restart and require a fresh review; an already-granted manual override remains your explicit independent decision.
